# Home

Welcome to the `open-chat-js` wiki.

This project is a lightweight JavaScript client for interacting with an Open-Chat server over HTTP. It focuses on small, dependency-free integrations for Node.js and browser-based apps.

## Overview

`open-chat-js` provides a compact wrapper around the Open-Chat API for:

- user authentication and token management
- chat creation and lookup
- sending messages
- listing recent messages

## Project status

This library is currently in beta. The public surface is intentionally small, and behavior is expected to evolve as the server API matures.
